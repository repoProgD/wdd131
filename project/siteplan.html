Website plan - Visual Chemistry

Website Plan

Site Name: Visual Chemistry

One of the major challenges in chemistry education is that many fundamental concepts are abstract, which makes them difficult for students to understand. Visual resources such as handouts, diagrams, and animations can help make these concepts more concrete and easier to grasp. For this reason, the name Visual Chemistry emphasizes the use of visual tools as a core approach to understanding chemical concepts.

Site Purpose

The purpose of this site is to provide visual tools to support the understanding of core chemistry concepts.

Scenarios

  • Which chemical groups are represented on this site?
  • How can a heatmap help me better understand chemical properties?

Color Scheme

The color scheme for this project is represented by the following HEX codes:

  • Primary Color: #23053E - Use for main background
  • Secondary Color: #3D2B56 - Use for header and footer backgrounds
  • Overlay Color: #EDEDED - Use for cards and other UI elements
  • Accent Color: #C5F5B2 - Use for interactive highlights, borders, and underlines
  • Text Color (light): #FEFEFE - Use for text on dark backgrounds
  • Text Color (dark): #000000 - Use for text on light backgrounds

Typography

  • Heading Font: Lora - Use for all headings
  • Body Font: Roboto - Use for all body text
